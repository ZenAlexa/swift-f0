## 项目核心原则

### 设计理念
1. **最小化复杂度** - 每个模块只做一件事
2. **配置驱动** - 通过YAML而非代码修改行为
3. **降级策略** - 每个功能都有简单备选方案
4. **增量开发** - 小步快跑，每步可验证

### 开发原则
1. **文档集中** - 只维护必要文档，持续更新
2. **代码精简** - 删除未使用代码，归档旧版本
3. **模块解耦** - 各组件独立，易于替换
4. **测试优先** - 先验证基础功能，再优化

## 项目目标

### 核心任务
**实现实时麦克风音色转换系统**
- 输入：麦克风/开发板音频流
- 处理：实时音高检测 + 音色变换
- 输出：转换后的音频流
- 延迟：<100ms

### 应用场景
1. **音色转换器** - 人声转换为任意乐器
2. **智能卡祖笛** - 硬件音色增强设备
3. **音乐教育** - 实时音高反馈工具
4. **创意表演** - 实时音效处理器

### 技术突破
- 低延迟音高检测（~80ms）
- 轻量级CNN模型（389KB）
- 实时音色合成
- 跨平台支持

## 当前开发阶段

### 🎯 v0.4.0 - 波表合成与音色优化 (2024-10-22) ✅ Alpha Demo

**状态**: 完成

**新增功能**:
- ✅ **波表合成系统** - 加法合成引擎
  - 实现文件: [additive_synthesizer.py](../swift_f0/realtime/additive_synthesizer.py)
  - 波表生成: [wavetable_generator.py](../swift_f0/realtime/wavetable_generator.py)
  - FFT-based 谐波合成
  - 线性插值查表，O(1)复杂度

- ✅ **3种乐器音色**
  - 长笛 (Flute) - 8个谐波
  - 小提琴 (Violin) - 16个谐波，1/n衰减
  - 单簧管 (Clarinet) - 12个谐波，奇数谐波强调

- ✅ **声音延续Bug修复**
  - 问题: 停止哼唱后声音持续数秒
  - 解决: 快速衰减机制（0.7倍/帧）
  - 效果: 0.1-0.2秒内静音

- ✅ **CLI增强**
  - `--instrument` 选择音色
  - `--synth` 选择合成器类型
  - 向后兼容简单正弦波模式

**技术指标**:
- 延迟: ~80ms
- 精度: <1% 音高误差
- 音色: 3种乐器 + 纯正弦波
- 波表大小: 16KB/乐器
- 采样率: 16kHz (检测) / 24kHz (输入)

**测试音频输出**:
- 位置: [test_data/audio_output/wavetable_synthesis/](../test_data/audio_output/wavetable_synthesis/)
- 16个WAV文件 (4音色 × 4音符)

**完整链路**:
```
ESP32麦克风 → USB Serial → SwiftF0检测 → 波表合成 → 扬声器
   24kHz        2Mbps      16kHz处理    长笛/小提琴    实时输出
                                        /单簧管
```
