```
│  │  3. 填充短音频 (确保 ≥256样本)                                  │  │
│  └──────────────────────────────────────────────────────────────┘  │
└─────────────────────────────────────┬───────────────────────────────┘
                                      ▼
┌─────────────────────────────────────────────────────────────────────┐
│                      SwiftF0 核心检测层                                │

│  │  ONNX模型推理 (model.onnx - 389KB)                            │  │
│  │                                                                │  │
│  │  输入: audio_16k [1, audio_length]                             │  │
│  │                                                                │  │

│  │  └──────────────────────────────────────────────────────┘    │  │

│  │  │  • 每层后接ReLU激活                                   │    │  │
│  │  │  → [time_frames, features]                           │    │  │
│  │  └──────────────────────────────────────────────────────┘    │  │
│  │                        ▼                                       │  │
│  │  ┌──────────────────────────────────────────────────────┐    │  │
│  │  │ Stage 3: 音高分类                                     │    │  │
│  │  │  • 1×1 Conv投影到音高类别空间                         │    │  │
│  │  │  • Softmax归一化                                      │    │  │
│  │  │  → [time_frames, n_pitch_classes]                    │    │  │
│  │  └──────────────────────────────────────────────────────┘    │  │
│  │                        ▼                                       │  │
│  │  ┌──────────────────────────────────────────────────────┐    │  │
│  │  │ Stage 4: 音高解码                                     │    │  │
│  │  │  • ArgMax找峰值                                       │    │  │
│  │  │  • Parabolic Interpolation (亚bin精度)               │    │  │
│  │  │  • 置信度计算 (概率分布尖锐度)                         │    │  │
│  │  └──────────────────────────────────────────────────────┘    │  │
│  │                                                                │  │
│  │  输出: pitch_hz [time_frames]                                  │  │
│  │        confidence [time_frames]                                │  │
│  └──────────────────────────────────────────────────────────────┘  │
└─────────────────────────────────────┬───────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────┐
│                      Python后处理层                                    │
│  ┌──────────────────────────────────────────────────────────────┐  │
│  │  Voicing判决:                                                  │  │
│  │    voiced = (confidence > threshold) &                         │  │
│  │             (fmin <= pitch_hz <= fmax)                         │  │
│  │                                                                │  │
│  │  时间戳计算:                                                    │  │
│  │    timestamps = (frame_idx * 256 + 127.5) / 16000             │  │
│  └──────────────────────────────────────────────────────────────┘  │
│                                                                     │
│  输出: PitchResult                                                  │
│    • pitch_hz: [62.5, 440.2, ...]                                  │
│    • confidence: [0.95, 0.88, ...]                                 │
│    • timestamps: [0.008, 0.024, ...]                               │
│    • voicing: [True, True, False, ...]                             │
└─────────────────────────────────────┬───────────────────────────────┘
                                      ▼
┌─────────────────────────────────────────────────────────────────────┐
│                      音符分割层 (music.py)                             │
│  ┌──────────────────────────────────────────────────────────────┐  │
│  │  segment_notes() 状态机算法:                                   │  │
│  │                                                                │  │
│  │  1. Hz → MIDI半音值                                            │  │
│  │     midi = 69 + 12 * log2(hz / 440)                           │  │
│  │                                                                │  │
│  │  2. 逐帧扫描:                                                   │  │
│  │     • voiced帧: 计算与当前音符的半音偏差                        │  │
│  │       - 偏差 < threshold → 继续当前音符                        │  │
│  │       - 偏差 ≥ threshold → 结束当前音符,开始新音符              │  │
│  │                                                                │  │
│  │     • unvoiced帧: 累积时长                                     │  │
│  │       - 时长 < grace_period → 容忍短暂静音                     │  │
│  │       - 时长 ≥ grace_period → 结束当前音符                     │  │
│  │                                                                │  │
│  │  3. 过滤: duration < min_note_duration → 丢弃                  │  │
│  │                                                                │  │
│  │  4. 量化: MIDI半音值 → round()到整数                           │  │
│  │                                                                │  │
│  │  5. 合并: 相邻同音高音符 → 合并                                │  │
│  └──────────────────────────────────────────────────────────────┘  │
│                                                                     │
│  输出: List[NoteSegment]                                            │
│    • start: 0.0s                                                    │
│    • end: 0.5s                                                      │
│    • pitch_median: 440.0 Hz                                         │
│    • pitch_midi: 69 (A4)                                            │
└─────────────────────────────────────┬───────────────────────────────┘
                                      ▼
┌─────────────────────────────────────────────────────────────────────┐
│              音色转换与调音层 (music_enhanced.py) ⭐ 新增              │
└─────────────────────────────────────────────────────────────────────┘
                                      │
                    ┌─────────────────┼─────────────────┐
                    ▼                 ▼                 ▼
        ┌──────────────────┐ ┌──────────────┐ ┌──────────────────┐
        │   调性检测        │ │   移调       │ │  卡祖笛优化       │
        │   (可选)          │ │   (可选)     │ │  (可选)           │
        └──────────────────┘ └──────────────┘ └──────────────────┘
                    │                 │                 │
                    ▼                 ▼                 ▼
        ┌──────────────────────────────────────────────────────────┐
        │  调性检测 (Krumhansl-Schmuckler)                          │
        │  ┌────────────────────────────────────────────────────┐  │
        │  │  1. 构建音高类直方图 (12 bins)                      │  │
        │  │     histogram[pitch_midi % 12] += duration          │  │
        │  │                                                      │  │
        │  │  2. 归一化                                           │  │
        │  │     histogram /= sum(histogram)                     │  │
        │  │                                                      │  │
        │  │  3. 与24种模板相关                                   │  │
        │  │     for key in [C, C#, D, ..., B]:                  │  │
        │  │       for mode in [major, minor]:                   │  │
        │  │         correlation = corrcoef(histogram, profile)  │  │
        │  │                                                      │  │
        │  │  4. 返回最高相关                                     │  │
        │  │     best_key, best_mode = argmax(correlations)      │  │
        │  └────────────────────────────────────────────────────┘  │
        │                                                            │
        │  输出: ("C", "major") 或 ("A", "minor") 等               │
        └────────────────────────────┬───────────────────────────────┘
                                     ▼
        ┌──────────────────────────────────────────────────────────┐
        │  自动调音 (Auto-Tune)                                      │
        │  ┌────────────────────────────────────────────────────┐  │
        │  │  1. 获取音阶音符                                     │  │
        │  │     scale = get_scale_notes(key, mode)              │  │
        │  │     例: C大调 → [0, 2, 4, 5, 7, 9, 11] (pitch class)│  │
        │  │                                                      │  │
        │  │  2. 量化每个音符                                     │  │
        │  │     for note in notes:                              │  │
        │  │       pitch_class = note.midi % 12                  │  │
        │  │       nearest = argmin(|pitch_class - scale[i]|)    │  │
        │  │       quantized_midi = octave*12 + scale[nearest]   │  │
        │  │                                                      │  │
        │  │  3. 按强度混合                                       │  │
        │  │     final = original*(1-strength) +                 │  │
        │  │             quantized*strength                      │  │
        │  └────────────────────────────────────────────────────┘  │
        │                                                            │
        │  输出: 修正后的音符列表                                    │
        └────────────────────────────┬───────────────────────────────┘
                                     ▼
        ┌──────────────────────────────────────────────────────────┐
        │  移调 (Transpose)                                          │
        │  ┌────────────────────────────────────────────────────┐  │
        │  │  for note in notes:                                 │  │
        │  │    note.midi += transpose_semitones                 │  │
        │  │    note.pitch_hz = 440 * 2^((midi-69)/12)           │  │
        │  └────────────────────────────────────────────────────┘  │
        └────────────────────────────┬───────────────────────────────┘
                                     ▼
        ┌──────────────────────────────────────────────────────────┐
        │  卡祖笛优化 (Kazoo Optimization)                           │
        │  ┌────────────────────────────────────────────────────┐  │
        │  │  1. 计算中值音高                                     │  │
        │  │     median = np.median([n.midi for n in notes])     │  │
        │  │                                                      │  │
        │  │  2. 计算最佳八度移动                                 │  │
        │  │     target = 64  # E4                               │  │
        │  │     shift = round((target - median) / 12) * 12      │  │
        │  │                                                      │  │
        │  │  3. 应用移动并限制范围                               │  │
        │  │     for note in notes:                              │  │
        │  │       note.midi += shift                            │  │
        │  │       note.midi = clamp(note.midi, 52, 76) # E3-E5  │  │
        │  └────────────────────────────────────────────────────┘  │
        └────────────────────────────┬───────────────────────────────┘
                                     ▼
┌─────────────────────────────────────────────────────────────────────┐
│                      MIDI导出层 (music_enhanced.py)                   │
│  ┌──────────────────────────────────────────────────────────────┐  │
│  │  export_to_midi_enhanced()                                     │  │
│  │                                                                │  │
│  │  1. 创建MIDI文件对象                                            │  │
│  │     mid = MidiFile()                                           │  │
│  │     track = MidiTrack()                                        │  │
│  │                                                                │  │
│  │  2. 设置元信息                                                  │  │
│  │     track.append(MetaMessage('track_name', ...))               │  │
│  │     track.append(MetaMessage('set_tempo', ...))                │  │
│  │                                                                │  │
│  │  3. 设置音色 (Program Change) ⭐ 新增                          │  │
│  │     track.append(Message('program_change',                     │  │
│  │                          program=GM_INSTRUMENTS[instrument]))  │  │
│  │                                                                │  │
│  │  4. 转换音符为MIDI事件                                          │  │
│  │     for note in notes:                                         │  │
│  │       # 计算时间 (秒 → MIDI ticks)                             │  │
│  │       ticks = seconds * (480 * tempo / 60)                     │  │
│  │                                                                │  │
│  │       # Note On                                                │  │
│  │       track.append(Message('note_on',                          │  │
│  │                            note=note.midi,                     │  │
│  │                            velocity=80,                        │  │
│  │                            time=delta_time))                   │  │
│  │                                                                │  │
│  │       # Note Off                                               │  │
│  │       track.append(Message('note_off',                         │  │
│  │                            note=note.midi,                     │  │
│  │                            velocity=80,                        │  │
│  │                            time=duration))                     │  │
│  │                                                                │  │
│  │  5. 保存文件                                                    │  │
│  │     mid.save(output_path)                                      │  │
│  └──────────────────────────────────────────────────────────────┘  │
│                                                                     │
│  输出: MIDI文件 (.mid)                                               │
└─────────────────────────────────────┬───────────────────────────────┘
                                      ▼
┌─────────────────────────────────────────────────────────────────────┐
│                        输出层                                         │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────────────────┐  │
│  │  MIDI文件     │  │  可视化图表   │  │  CSV数据导出              │  │

```

## 数据流示例

### 示例1: 基础音色转换

```
输入: "song.wav" (44.1kHz, 立体声, 3.5秒)
                 ▼
预处理: → 16kHz单声道 (56000样本)
                 ▼
音高检测: → PitchResult
              - 218帧
              - pitch_hz: [261.6, 261.8, 262.1, ...]
              - confidence: [0.95, 0.94, 0.96, ...]
              - voicing: [T, T, T, F, F, T, ...]
                 ▼
音符分割: → 12个NoteSegment
              1. C4 (0.0s - 0.5s)
              2. E4 (0.5s - 1.0s)
              3. G4 (1.0s - 1.5s)
              ...
                 ▼
MIDI导出: → "output.mid"
              - Track: "SwiftF0 Enhanced"
              - Tempo: 120 BPM
              - Instrument: Program 56 (Trumpet)
              - 12 Note On/Off事件
```

### 示例2: 自动调音流程

```
输入音符: [C4, C#4, E4, F4, G4, G#4, B4]
           (有些音跑调了)
              ▼
调性检测: 分析音高类分布
           [C: 20%, C#: 5%, D: 0%, ..., B: 15%]
           ▼
           相关分析: C大调相关度 0.89 ✓
                    A小调相关度 0.65
           ▼
           检测结果: C major
              ▼
获取音阶: C大调音阶 = [C, D, E, F, G, A, B]
              ▼
量化音符:
  C4 → C4 (已在音阶内,不变)
  C#4 → C4 或 D4 (量化到最近音阶音)
  E4 → E4 (已在音阶内,不变)
  F4 → F4 (已在音阶内,不变)
  G4 → G4 (已在音阶内,不变)
  G#4 → G4 或 A4 (量化到最近音阶音)
  B4 → B4 (已在音阶内,不变)
              ▼
修正后: [C4, C4, E4, F4, G4, A4, B4]
         (所有音符都在C大调音阶内)
```

### 示例3: 卡祖笛优化流程

```
输入音符: [C3, D3, E3, ..., C6, D6, E6]
           (音域: 48-88, 超出卡祖笛范围)
              ▼
计算中值: median = 68 (G#4)
              ▼
计算移调: target = 64 (E4, 卡祖笛中心)
           shift = round((64-68)/12) * 12 = 0
              ▼
应用限制:
  C3 (48) → C4 (60) (提高1个八度)
  D3 (50) → D4 (62) (提高1个八度)
  E3 (52) → E3 (52) (已在范围内)
  ...
  C6 (84) → C5 (72) (降低1个八度)
  D6 (86) → D5 (74) (降低1个八度)
  E6 (88) → E5 (76) (降低1个八度)
              ▼
优化后: 所有音符在 52-76 (E3-E5) 范围内
```

## 关键算法时间复杂度

| 算法 | 时间复杂度 | 说明 |
|------|-----------|------|
| STFT | O(n log n) | n = 音频长度 |
| CNN推理 | O(k·t·f) | k=卷积核数, t=时间帧, f=频率bin |
| Voicing判决 | O(t) | t = 帧数 |
| 音符分割 | O(t) | 单次扫描 |
| 调性检测 | O(24·m) | m = 音符数, 24 = 调性数 |
| 音高量化 | O(m·s) | s = 音阶音数(7) |
| MIDI导出 | O(m) | m = 音符数 |

## 内存占用估算

以3分钟音频为例（180秒）：

```
原始音频 (16kHz, float32):
  180s × 16000 samples × 4 bytes = 11.52 MB

STFT频谱:
  ~11,250 帧 × 513 频率bin × 4 bytes ≈ 23 MB

CNN中间特征:
  最大层: ~11,250 帧 × 64 通道 × 513 bin × 4 bytes ≈ 1.5 GB
  (但ONNX会自动管理内存,实际峰值约 200-300 MB)

PitchResult:
  4个数组 × 11,250 × 8 bytes ≈ 360 KB

NoteSegment列表:
  ~500个音符 × 32 bytes ≈ 16 KB

总峰值内存: ~350 MB (合理)
```

### 3. 实时流式接口

```python
class RealtimeProcessor:
    def __init__(self, detector):
        self.detector = detector
        self.buffer = RingBuffer(size=16000)  # 1秒缓冲

    def process_chunk(self, audio_chunk):
        """处理实时音频块"""
        self.buffer.append(audio_chunk)
        if self.buffer.is_ready():
            result = self.detector.detect_from_array(
                self.buffer.get(), 16000
            )
            return result
```
